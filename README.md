# Meu dia

Planejador diário simples em uma única página HTML. Sem build, sem servidor: abra o `index.html` no navegador.

## O que tem

- **Hábitos**: coisas que se repetem, com dias da semana, sequência (🔥) e últimos 7 dias.
- **Hoje**: tarefas do dia, com prioridade, edição direta e arrastar para reordenar.
- **Caixa de ideias**: anote sem pensar e puxe para hoje quando decidir. Atalho: tecla `N`.
- Barra de progresso do dia e tema claro/escuro automático.

## Como usar

```
git clone <url-do-repo>
cd planos
xdg-open index.html
```

Os dados ficam salvos no `localStorage` do navegador.
